# Hiddify-WhiteLabel

**نسخه ثبت‌شده در فایل VERSION:** `1.3.18`  
**وضعیت پروژه:** در حال توسعه؛ پذیرش نهایی اتصال زنده به پنل‌ها هنوز کامل نشده است.

Hiddify-WhiteLabel یک پلتفرم چندمستاجری برای مدیریت کسب‌وکارهای فروش اشتراک VPN از طریق تلگرام است. مدیر پلتفرم با MasterBot مستأجرها و لایسنس‌ها را مدیریت می‌کند و هر مستأجر ربات AdminBot و UserBot اختصاصی خود را دارد. ربات‌ها در یک Runtime اشتراکی و چندبخشی اجرا می‌شوند.

## قابلیت‌های اصلی

- مدیریت مستأجرها، پلن‌ها، لایسنس‌ها و چرخه انقضا
- جداسازی داده و دسترسی هر مستأجر
- فروش، تمدید، پرداخت، بررسی رسید و کیف پول
- کد تخفیف، معرفی دوستان و تست رایگان
- مدیریت کاربران، سرویس‌ها، تیکت‌ها و گزارش‌ها
- اتصال به Hiddify Manager، X-UI Sanaei، X-UI Alireza و X-NET
- اشتراک چندنودی، تجمیع مصرف و لینک هوشمند
- نصب، مدیریت systemd، بررسی سلامت و بکاپ رمزنگاری‌شده

## وضعیت فنی و محدودیت‌ها

- نسخه فعلی ثبت‌شده در فایل `VERSION` برابر `1.3.18` است.
- پایگاه داده فعلی فقط SQLite است؛ پشتیبانی PostgreSQL پیاده‌سازی نشده است.
- تست‌های آفلاین و اسکریپت release drill وجود دارند.
- پذیرش زنده پنل‌ها و ثبت آزمون rollback هنوز در Roadmap ناقص است.
- رابط فعلی ربات‌ها فارسی است؛ مستندات توسعه‌دهندگان انگلیسی هستند.

## راه‌اندازی محیط توسعه

```bash
git clone https://github.com/mojtaba-glx/Hiddify-WhiteLabel.git
cd Hiddify-WhiteLabel

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

pytest -q
python scripts/release_drill.py
```

برای نصب و عملیات، راهنمای [Operations](docs/OPERATIONS.md) و برای پذیرش نهایی، [Staged Release Drill](docs/STAGED_RELEASE_DRILL.md) را بخوانید.
